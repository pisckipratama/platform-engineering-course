Welcome to my learning documentation repository. This space is dedicated to my journey of deep-diving into the **Platform Engineering** discipline—transitioning from traditional DevOps practices to building robust **Internal Developer Platforms (IDP)** using **Backstage.io**.

## 🎯 Learning Objectives
- Architecting a "Product Mindset" for internal infrastructure.
- Reducing **Cognitive Load** for developers through self-service capabilities.
- Implementing **"Golden Paths"** for standardized software delivery.
- Mastering the **Backstage** ecosystem (Software Catalog, Scaffolder, and TechDocs).

---

## 🛠️ Tech Stack & Tooling
Throughout this course, I am gaining hands-on experience with:
- **Platform Orchestrator:** Backstage (Spotify's Framework)
- **Infrastructure:** Kubernetes, Docker
- **IaC:** Terraform / Crossplane
- **CI/CD:** GitHub Actions / ArgoCD
- **Documentation:** TechDocs (Docs-as-Code)
